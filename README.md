# Encapsulamento — Tamagotchi

O **Encapsulamento Tamagotchi** é um projeto desenvolvido em Java para praticar os conceitos de **Programação Orientada a Objetos (POO)**, com foco no uso de **encapsulamento**.

O sistema simula um **bichinho virtual**, que possui características como nome, fome, energia e humor. Os atributos são protegidos dentro da classe e controlados por métodos específicos, evitando alterações diretas e mantendo as regras do sistema organizadas.

### Funcionalidades

* Definição do nome do bichinho;
* Controle do nível de fome;
* Controle da energia;
* Alteração do humor de acordo com os atributos;
* Alimentação do bichinho;
* Realização de ações que afetam seus atributos;
* Consulta do estado atual do bichinho;
* Validação dos valores para evitar estados inválidos.

### Conceito utilizado

O principal conceito trabalhado é o **encapsulamento**, utilizando atributos privados e métodos para controlar o acesso e as alterações nos dados do bichinho virtual.

### Objetivo

O objetivo do projeto é praticar **classes, objetos, atributos privados, métodos, getters e setters**, além de entender como o encapsulamento pode ser utilizado para proteger os dados e controlar o comportamento de um objeto em Java.
